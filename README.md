# Retrogame shop UI

## About

Retogame is a small landing-style shop for selling retro games and game consoles.

## Technologies stack

- JS Library for UI building: React 19
- Programming language: Typescript 5.9
- Router: React Router
- UI Components Library: PrimeNG React
- Form management: React Hook Form
- State management: Zustand (if needed)
- Server state management & data fetching: Tanstack Query
- Build tool: Vite
- Backend mockup: MSW
- UI Documentation: Storybook
- Architecture: Feature Sliced Design
- AI Tools: Claude code
